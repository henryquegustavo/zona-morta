# Zona Morta

Jogo de sobrevivência zumbi no navegador (PC e celular), com salas para jogar com amigos.

- **Jogar sozinho:** abra o site e toque em JOGAR SOZINHO.
- **Jogar com amigos:** coloque seu nome e toque em CRIAR SALA. Passe o código de 4 letras (ou o botão CONVIDAR) para os amigos, que entram com ENTRAR.
  Quem cria a sala é o anfitrião: a cidade e os zumbis são os mesmos para todos.

A sala usa o Supabase Realtime (Broadcast). O jogo é um único `index.html`, sem etapa de build.
